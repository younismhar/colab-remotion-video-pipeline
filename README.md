# Colab Remotion Video Pipeline

An automated, cloud-based programmatic video production pipeline for educational science content, built with Python, React/Remotion 4.0, Deepgram, and FFmpeg.

## Features
- **Automated Voice & Sync:** Generates voiceovers and maps millisecond-accurate word timestamps using Deepgram (`nova-2`).
- **Programmatic Motion Graphics:** Uses React and Remotion 4.0 for kinetic typography, 2.5D parallax, and automated 3–4 second visual pacing.
- **Cloud-First Workflow:** Designed to run on Google Colab and scale to AWS Lambda without requiring local high-end GPU hardware.
